# Production Environment Variables

This inventory is derived from `apps/api/src/lib/env.ts`, API/desktop `.env.example` files, and the
Electron main-process configuration. Never paste secret values into this document or commit `.env`.
Local `.env` files exist but their contents were not read; current tracked files contain only
`.env.example` templates. A full secret scan of all Git objects was not run.

### Template variables not read by current API

`SMTP_URL`, `AI_PROVIDER`, and `AI_API_KEY` appear in `.env.example` as future configuration notes,
but `loadEnv()` does not read them and the current API has no real email provider/AI provider wired.
The invitation transport explicitly does not send email; it returns an invite link in the app and logs
redacted metadata. Do not set these variables expecting those features to activate.

## Windows desktop release

| Variable                       | Handling                                                                                                                                                                                                                                                                      | Status               |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------- |
| `BT_API_BASE_URL`              | Read at Electron main-process runtime; overrides the API base. Packaged default remains `https://api.buildtogether.app`. The desktop `.env` is excluded from the installer and is not loaded by the main process, so a Windows install has no built-in Railway URL injection. | NEEDS IMPLEMENTATION |

| `VITE_CLERK_PUBLISHABLE_KEY`   | Public Clerk key embedded by the Vite renderer build; use the same production Clerk instance as the API. It is not a server secret.                                                                                                                                           | NEEDS USER ACTION    |
| `VITE_CLERK_FRONTEND_API_HOST` | Optional public host override documented in desktop template; verify whether required for the chosen Clerk instance before release.                                                                                                                                           | NEEDS USER ACTION    |

Do not prefix Clerk Secret Keys, database credentials, Nexconn App Secret, or session secrets with
`VITE_`. Secret values were intentionally not printed or included in this audit.
